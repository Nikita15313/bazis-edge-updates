# Кромка БАЗИС — обновления

Канал обновлений дополнения «Кромка БАЗИС». Только установщики, номера версий и подписанные сведения об обновлении. Рабочие файлы, база материалов, лицензия и исполняемые файлы самого БАЗИС сюда не загружаются.

[Скачать установщик](https://github.com/Nikita15313/bazis-edge-updates/releases/latest/download/BazisEdgeSetup.exe)

Обновление: значок дополнения возле часов → «Проверить обновления» → «Обновить».

Установщик работает в профиле пользователя. Сохраните работу и перезапустите БАЗИС после обновления, если он был открыт.
