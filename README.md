# Кромка БАЗИС — обновления

[Скачать последнюю версию](https://github.com/Nikita15313/bazis-edge-updates/releases/latest/download/BazisEdgeSetup.exe)

В 9.8 обновлено меню, добавлены автоматические уведомления об обновлениях и ввод своего названия материала текущего заказа. Расчёты и TXT для 1С остаются отдельным дополнением.

Установите последнюю версию один раз. Установщик работает в профиле пользователя без запроса прав администратора. Если БАЗИС открыт, сохраните работу и после установки полностью закройте и откройте его.

Версии 9.6/9.7 можно обновить через значок кромки возле часов → «Проверить обновления» → «Обновить». Для более старых версий используйте установщик по ссылке выше. Промежуточные версии по очереди не нужны.

Начиная с 9.8.3 дополнение само проверяет подписанный канал через секунду после запуска, затем примерно каждую минуту и при открытии меню. Запрос получает свежие сведения с обходом кеша; при временной ошибке повторяется через минуту без окон ошибок. Новая версия отмечается уведомлением, красной точкой на значках и кнопкой «Доступно обновление» в меню кромки. Установка начинается по нажатию пользователя.

«Свой материал…» меняет название в текущем заказе, сохраняет текущий артикул и параметры плиты и не добавляет материал в базу. После изменения сохраните ОБЛ обычным способом. Первую проверку нового имени проведите на копии заказа: живой цикл сохранения и повторного открытия ОБЛ для этой функции пока не проверен.

Поддерживаемые точные сборки БАЗИС-Раскрой: 2021.11.1.32943, 10.5.0.25314, 10.6.2.25670, 2022.12.21.36090. Совместимость с произвольными другими сборками не заявляется.

Здесь публикуются только установщики самого дополнения и подписанные сведения об обновлении. Рабочие заказы, база материалов, лицензия и исполняемые файлы БАЗИС не загружаются.
